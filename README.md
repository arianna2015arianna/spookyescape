# Spooky Escape — Enhancements (proposed)

This branch adds several files to make Spooky Escape more interactive:

- index.html — new UI with on-screen controls and inventory
- styles.css — responsive, themed styling
- game.js — a small game engine: rooms, items, interactions, inventory, save/load, keyboard support, simple sound

How to try locally
1. Add the files to your repository (root).
2. Open `index.html` in a browser (no server required).
3. Use arrow keys or on-screen arrows to move. Press L to look, T to take the first portable item, or use the UI buttons.

If you want me to commit these files to the `enhance-game` branch in your repository, reply: "Commit to enhance-game" and I'll push them there.
